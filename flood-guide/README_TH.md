# /flood-guide/ วิธีใช้พร้อมแจ้งน้ำท่วม (มีภาพทีละขั้น)

- หน้าคู่มือสำหรับประชาชน หน่วยงาน มูลนิธิ และอาสาสมัคร
  - อธิบายหน้า `/flood/` ทีละขั้นด้วยภาพจากเว็บจริง
  - บอกตรง ๆ ว่าส่วนไหนเปิด และส่วนไหนยังไม่เปิด
  - มีไฟล์ให้ดาวน์โหลด
- ปุ่มโทร 1784 และ 1669 อยู่บนสุด
- หน้าไม่มี JavaScript
- CSP ห้ามสคริปต์และห้ามเชื่อมต่อเว็บอื่น
- ทุกไฟล์อยู่ในโฟลเดอร์นี้ ยกเว้นไอคอน `../flood/icon.svg`

## ที่มาของภาพ

- `img/*.jpg` คือภาพหน้าจอเว็บจริง titanth.com/flood/ และ /flood-neighbors/ หลัง PR #49 (main `52a822f`)
  - ถ่ายเมื่อ 27 ก.ย. 2569 ด้วย Chrome โปรไฟล์ทิ้ง ขนาดจอ 390 px
  - ไม่กดโทร ไม่เปิด LINE ไม่แชร์ และไม่ส่งอะไร
- ข้อมูลในภาพเป็นตัวอย่างทั้งหมด:
  - จุดสังเกตและรายละเอียดขึ้นต้นด้วย "ตัวอย่าง:"
  - เบอร์โทรกลับเป็น `08X-XXX-XXXX`
  - ตำแหน่งจำลองอยู่กลางเมืองนครราชสีมา ซึ่งเป็นที่สาธารณะ
- QR ตัวอย่างในภาพขั้นที่ 3 ถูกเบลอและปิดทับ
  - ไม่ให้ใครสแกนข้อความขอความช่วยเหลือปลอมไปส่งต่อ
  - ตรวจด้วย CoreImage แล้วว่าสแกนไม่ได้
- `cards/*.png` เป็นภาพ 1080×1350 จำนวน 14 ใบสำหรับโพสต์ สร้างจากภาพชุดเดียวกัน
  - ภาพปก `c00_cover.png` มี QR ไป `https://titanth.com/flood/` ตรวจแล้วว่าสแกนได้ตรง
- `files/promjaeng-flood-pack-20260927.pdf` คือชุดข้อมูล 5 หน้าสำหรับหน่วยงาน
- สคริปต์ถ่ายภาพ ประกอบภาพ ทำ PDF และผลตรวจอยู่ในโฟลเดอร์หลักฐานของ Claude: `sot-20260925/flood/public_guide_20260927/`

## เมื่อหน้า /flood/ เปลี่ยน

- ภาพในหน้านี้จะเก่าทันที
- ต้องถ่ายใหม่ด้วย `make_all.sh` ในโฟลเดอร์หลักฐาน แล้วตรวจคำอธิบายทุกขั้นให้ตรงกับปุ่มจริง

## ทดสอบ

- `flood_guide_browser_check.mjs` ในโฟลเดอร์หลักฐาน
- ตรวจที่ความกว้าง 320, 360 และ 390 px และที่ตัวอักษร 200%
- สิ่งที่ตรวจ:
  - ภาพโหลดครบ
  - ไม่มีตัวอักษรเล็กกว่า 14 px
  - ไม่มีปุ่มหรือลิงก์เดี่ยวที่เล็กกว่า 44 px
  - ไม่ขอข้อมูลจากเว็บอื่น
  - ลิงก์ในหน้าและไฟล์ทุกไฟล์เปิดได้
