# /flood-water/ ระดับน้ำและฝนในจังหวัดของคุณ (ข้อมูลสด สสน.)

- ผู้ใช้เลือกจังหวัดแล้วกด "ดูข้อมูลล่าสุด"
- หน้าขอข้อมูล 2 อย่างจาก API ของ thaiwater.net (คลังข้อมูลน้ำแห่งชาติ, สสน.) เฉพาะจังหวัดนั้น
  - `waterlevel_load?province_code=`
  - `rain_24h?province_code=`
- สิ่งที่แสดง:
  - สถานีที่น้ำเกินตลิ่ง
  - สถานีที่น้ำ 70–100% ของตลิ่ง พร้อมแนวโน้มน้ำขึ้น ลง หรือทรงตัว
  - ฝน 24 ชั่วโมงสูงสุด 5 สถานี
  - เวลาของข้อมูล และลิงก์ไป thaiwater.net
- แสดงผลด้วย `textContent` ทั้งหมด
- ไม่เก็บอะไรในเครื่อง และไม่มี service worker

## ที่มาและข้อจำกัด

- API นี้เป็นตัวที่ thaiwater.net ใช้เอง ไม่พบเอกสารทางการ รูปแบบจึงอาจเปลี่ยนได้
  - ถ้าคำตอบผิดรูป หน้าจะบอกว่า "ดึงข้อมูลไม่สำเร็จ" ไม่แสดงเป็นว่าไม่มีข้อมูล
  - ทุกหน้ามีลิงก์ไป thaiwater.net
- `situation_level` 5 = น้ำเกินตลิ่ง (มากกว่า 100%) และ 4 = 70–100% ตรงกับ `storage_percent` ทุกสถานีที่มีค่า (ตรวจ 789 สถานี 27 ก.ย. 2569)
- ไม่แสดงข้อมูลที่เก่ากว่า 3 ชั่วโมง
- สถานีเป็นจุดวัด ไม่ได้แทนทั้งจังหวัด
- ข้อมูลเปิดของ สสน. ใช้สัญญา CC BY-NC: ใช้แบบไม่หาเงินและระบุที่มา ซึ่งหน้านี้ทำทั้งสองอย่าง
- ชุดข้อมูลรายเดือนใน data.hii.or.th เป็นข้อมูลย้อนหลัง (ล่าสุด ก.ค. 2569) จึงไม่ได้ใช้ในหน้านี้
- `province_codes.js` สร้างจากรายการจังหวัดของ API และตรวจแล้วว่าครอบคลุมครบ 77 ชื่อใน `../flood/provinces.js`
