งานเดินต่อได้
ข้อสงสัยเดิมยังอยู่

ตัวอย่างเตรียมหน้าแนะนำงานหนึ่งหน้า ข้อความงานและความคืบหน้าทั้งหมดสร้างขึ้นเพื่อสาธิต ไม่ใช่งานลูกค้าหรือผลทดสอบเว็บไซต์จริง แต่ใบรับรองการบันทึกมาจากการเรียก native core จริงและตรวจลายเซ็นแล้ว

เป้าหมายและข้อกำหนดเดิม

เตรียมหน้าแนะนำงานหนึ่งหน้า โดยต้องบอกขอบเขตที่ทำได้จริง ตรวจลิงก์ และตรวจจอมือถือก่อนส่งมอบ

รอบข้อความที่ส่งเข้าผลที่คืน
1เริ่มร่างหน้าแนะนำงาน ยังต้องตรวจลิงก์และจอมือถือบันทึกข้อความและข้อกำหนด มีข้อสงสัยเรื่องลิงก์และมือถือ
2เพิ่มข้อความอธิบายขอบเขตในร่างแล้ว ยังต้องตรวจลิงก์และจอมือถือผูกกับรอบแรก รักษาข้อสงสัยเดิม และเพิ่มว่ายังไม่ได้ทดลองกับผู้ใช้จริง

แม้ข้อความรอบใหม่เปลี่ยน ระบบไม่ได้ลบข้อสงสัยเดิมหรือสรุปว่างานเสร็จ

เปิดไฟล์ต้นทางและผลจริง

  • Input รอบ 1 · Output และใบรับรองรอบ 1
  • Input รอบ 2 · Output และใบรับรองรอบ 2
  • รายการ SHA-256 และขอบเขตตัวอย่าง · คำอธิบายไฟล์ฉบับข้อความ

รอบ 2 อ้างหัวประวัติรอบ 1 นี้:

976144539b7272cc365b6fd04bd5b7c806c56187d7f029c00dfa9d2d4c6eb1af

หัวประวัติรอบ 2:

e1d9a33689d34232c3d6dc9aee4262294f71768dab106bc39c0430ccf0732cea

ใบรับรองนี้พิสูจน์ได้แค่ไหน

Output มีสถานะ RECORDED_ONLY และ packet ที่ผูกข้อความ ข้อกำหนด ข้อสงสัย และประวัติพร้อมลายเซ็น เป็น local workbench recording receipt ด้วยกุญแจสังเคราะห์ใหม่ ไม่ใช่การยืนยันตัวบุคคลหรือใบรับรองจากหน่วยงานอิสระ

factual_truth_verified, completion_established และ effect_authorized เป็น false ใบรับรองไม่ได้พิสูจน์ว่าได้ตรวจลิงก์จริง งานเสร็จ หรือมีสิทธิ์ลงมือภายนอก ไม่ใช่ historical receipt.062 ของเจ้าของ

ตัวอย่างเผยแพร่เฉพาะข้อความสังเคราะห์และลายเซ็น/กุญแจสาธารณะที่จำเป็นต่อการตรวจ ไม่มี private key, token, รหัสบัญชี หรือ runtime ให้ดาวน์โหลด
