How to use it

  1. Export products from Shopify; copy SKU, product and variant into the template.
  2. Send the template to each supplier with the manufacturer-code and barcode columns empty (email text).
  3. Paste answers back, set the status column, note the source.
  4. Load the file in the checker and map the columns; or keep it beside your Shopify export.

Questions

Can I send this file to my carrier?

Ask them. Most express carriers take the values per line item on the commercial invoice or in their shipping tool; the template is the source you copy from.

Why a status column?

A blank barcode is ambiguous. 'confirmed_none' records that the maker confirmed there is no barcode, which is what Y081 requires.
