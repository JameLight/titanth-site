Storing the maker's code in Shopify

Short answer: Create a variant metafield (for example custom.manufacturer_code, single line text), fill it per variant from your supplier answers, then export products and confirm the metafield column is present. If your export does not show it, keep a side sheet keyed by SKU and map that column in the checker.

Steps

  1. Shopify admin → Settings → Custom data → Variants → Add definition. Name: "Manufacturer code". Namespace and key: custom.manufacturer_code. Type: single line text. Save.
  2. Open each product → variant → scroll to Metafields → enter the maker's model or part number exactly as the supplier wrote it.
  3. For many variants, use Shopify's bulk editor (Products → select → Bulk edit) and add the metafield column.
  4. Products → Export → CSV. Open the file and look for a column named like Manufacturer code (product.metafields.custom.manufacturer_code) or similar. If it is there, you are done.
  5. If it is not there, export the metafield with a CSV app, or keep a simple side sheet: columns Variant SKU, Manufacturer code, Source. In the checker, choose that column under "Match identifier columns".

Why a variant metafield and not the product-level MPN

The Google Shopping / MPN column is product-level. If a product has sizes or colours with different maker codes, product-level storage cannot express that. A variant metafield can.

Rules of thumb

  • Enter the code exactly; do not "clean" it.
  • Record where it came from (supplier sheet, packaging, email) in a second metafield or your side sheet.
  • If the maker uses the same code for every variant, entering it on each variant is still correct.

Questions

Which Shopify plan is needed for metafields?

Metafield definitions are available on all current Shopify plans.

Can the free checker read my metafield column?

Yes, if the column is in the CSV you load. Use the 'Match identifier columns' panel to point the maker's-code field at it.
