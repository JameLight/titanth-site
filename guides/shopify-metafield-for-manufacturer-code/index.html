Storing the maker's code in Shopify

Short answer: Shopify now offers an NS-PID type in each variant's Barcodes. Confirm the supplier-issued code for each exact variant; this store has not tested its Product CSV round trip or carrier handoff. A defined product metafield remains a possible Product CSV route for one product-level value. Variant metafields are excluded from Product CSV. A Shopify CSV does not itself send identifiers to a carrier or customs broker.

Native NS-PID type in variant Barcodes

Shopify admin now offers NS-PID as a barcode type for each variant; Shopify also lists NS_PID in its BarcodeType API reference. Confirm the actual code with the maker or supplier, then test a fresh export and controlled re-import on an archived test product before relying on the CSV route. The exact CSV prefix, round trip and carrier handoff are still unverified for this store. The currently delivered 0.3.2.4 checker has not been verified to recognize this typed value, so a blank-code finding is not proof that Shopify lacks the value.

Possible Product CSV route for a single-variant product

In Shopify admin, define a single-line product metafield under Settings → Custom data (or Metafields and metaobjects) → Products, for example Manufacturer code with namespace/key custom.mfr_code. Shopify says a defined product metafield appears in Product CSV import/export under a header such as Manufacturer code (product.metafields.custom.mfr_code). Export a fresh CSV and check the actual header. Before treating it as NS-PID, confirm that the maker or supplier assigned this code to the exact item. This store has not completed a product-metafield CSV import/re-export test. Do not import TITANTH review worksheets. A Shopify import can overwrite blank included fields; omitting variant option columns can remove variants, and omitting Status can default a product to active. Preserve a full backup, review every column and all variant rows, and test on an isolated product before considering a wider import. Shopify CSV documentation.

Alternative: a variant metafield or side sheet

  1. Shopify admin → Settings → Custom data → Variants → Add definition. Name: "Manufacturer code". Namespace and key: custom.manufacturer_code. Type: single line text. Save.
  2. Open each product → variant → scroll to Metafields → enter the maker's model or part number exactly as the supplier wrote it.
  3. For many variants, use Shopify's bulk editor (Products → select → Bulk edit) and add the metafield column.
  4. Variant metafields are not included in product CSV export or import; Shopify points to the variant bulk editor for editing them in bulk. To keep a copy you can check, use a simple side sheet: columns Variant SKU, Manufacturer code, Source.
  5. To check the codes, add your code column to the CSV you load and choose it under "Match identifier columns" in the checker.

What appears in the product CSV

  • Typed Barcodes: Shopify has an NS-PID type per variant, but its exact Product CSV serialization and round trip have not been verified in this store. Inspect a fresh export before assuming it is present or accepted on import.
  • Google Shopping MPN column: not always. Shopify's help page and sample files show it, but a real export from our own store on 25 September 2026 had no Google Shopping columns at all, even though the test products had MPN values. Open your own export and check the headers.
  • Product metafield: included once defined, according to Shopify's documentation; in Shopify's sample file the value sits on the product's first row only. Check one multi-variant product in your own export before relying on it. It holds one value per product, so it suits only a product sold in one version.
  • Variant metafield: no. Use the variant bulk editor or a side sheet.

The Commission guidance (section 3.5.3) says each identifier should point to exactly one product variant, so products sold in several sizes or colours usually need a code per variant.

Rules of thumb

  • Enter the code exactly; do not "clean" it.
  • Record where it came from (supplier sheet, packaging, email) in a second metafield or your side sheet.
  • If the maker says one code covers every variant, record that answer and where it came from. The guidance expects one code per variant, so ask whether a per-variant code exists.

Questions

Which Shopify plan is needed for metafields?

Metafield definitions are available on all current Shopify plans.

Can the free checker read my metafield column?

Yes, if the column is in the CSV you load. Use the 'Match identifier columns' panel to point the maker's-code field at it.
