IOSS, EORI, HS code and product identifiers

Short answer: IOSS is a VAT scheme number for the seller; EORI identifies a trader to customs; the HS code classifies what the goods are for duty; product identifiers (M-PID, NS-PID, S-PID) identify the exact item. Having an HS code or IOSS number does not give you product identifiers.

Typical misunderstanding

"We already put HS codes on every parcel, so we are fine." HS codes say what kind of thing it is (e.g. leather gloves); product identifiers say which exact product from which maker. Both are needed from 1 November 2026 for consumer parcels.

Questions

I use IOSS — do I still need product identifiers?

Yes. IOSS handles VAT collection; product identifiers are data on the customs declaration. Both apply.

Is the HS code one of the product identifiers?

No. The three identifiers are the merchant code, the manufacturer code and the standardised barcode. The HS code is a separate classification field.
