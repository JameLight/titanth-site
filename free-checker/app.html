Take the work forward

These are review worksheets, not Shopify import files or customs declarations.

The corrected review CSV keeps source columns and rows, including image rows. Spreadsheet protections may add apostrophes. The separate protection log explains those changes; JSON preserves exact values. This is not a certified Shopify or carrier import file.

CSV exports escape spreadsheet-formula prefixes. JSON preserves original text; treat it as data, not code.

A data check, not a compliance certificate.

The tool identifies missing values, candidates and data-format concerns. It cannot verify that a manufacturer issued a code, decide every legal exception, or guarantee acceptance by a carrier or customs authority.

Three codes are involved: your own product code (usually the SKU — customs calls it M-PID), the maker's or supplier's product code (NS-PID), and the retail barcode such as GTIN / EAN / UPC where one exists (S-PID). A blank cell does not prove that a code does not exist.
